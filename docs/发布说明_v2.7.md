# SerialAssistant V2.7 发布说明

> 适用对象：2026 中国大学生方程式 · 重庆大学方程式赛车队
> 版本：**V2.7**（2026-11-11）

## 一句话

本版本把 **SOC 估算**做成了可在 **ECU** 上复现的纯逻辑模块，配套一份给电控同学的总操作指南；同时加入性能模式浮层、小米手环心率 DLC，并加固了全部自检。

## 主要变更

- **SOC 估算（核心）**
  - 安时积分（骨架）+ κ 加权 OCV 回拉 + 静置软锚定（唯一强校正）+ 电流零漂在线学习。
  - 不上完整 EKF（采样抖动 0.9~2.5 s + 电流零漂会让协方差发散）；设置里可切四状态二阶 RC-PNGV EKF。
  - 底栏显示 **SOC min / max** 双读数（放电突出 min、充电突出 max）+ 总压 + 工况标记。
  - 清洗严格区分「断线回填」与「整模组不均衡保真值」；超量程必然回填，避免把接线故障伪装成没电。
  - 实测精度：闭环回放最大偏差 1.38%、静置与 OCV 查表一致 0.09%、零漂收敛约 1.41 A，SOC 永不越界 0~100。

- **ECU 移植操作指南（新增）**
  - `SOC/SOC跑在ECU的操作步骤.pdf`：系统架构（BMS→CAN→ECU→CAN→C125）、输入数据契约、6 步算法（含公式）、E74 参数一页纸（26 点 OCV 表）、ECU→C125 的 DBC/帧布局、联调验收判据。
  - 算法模块 `soc_est.py` / `soc_feed.py` / `soc_profiles.py` 纯 Python、无 Qt 依赖，可直接移植到 ECU。

- **性能模式浮层（od78）**：队标手势触发，真高斯模糊（einsum 向量化），整流 + 手势 + 浮层。
- **小米手环心率 DLC（heartbeatDLC）**：BLE 广播心率接入，多设备、单 QThread 事件循环。
- **自检加固**：真实平台 36/36 全绿；offscreen 下两条字体度量断言按既有标准跳过（真实平台已验证）；新增 SOC/EKF/历史时间戳/工况判别等验证器。

## 升级方式

- 老用户：直接静默替换为 `SerialAssistant.exe`。
- 安装版用户：运行 `SerialAssistant-setup-2.7.exe`。

## 已知边界

- 只支持**等长模组**；不规则模组（如 `A08-2026` 的 20/20/20/20/26）显示 `--`。
- E74 无带真实 SOC 标签的放电记录，精度指标为自洽性/一致性，非绝对精度；需带库仑计满充→满放标定方可进一步收敛。
