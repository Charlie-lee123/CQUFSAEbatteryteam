## 一、结论先说

| 项目 | 当前 26 点表 | 原始 62 点表 |
|---|---|---|
| 正向 OCV 误差 max | **59.55 mV** | **0.01 mV** |
| 正向 OCV 误差 RMS | 5.22 mV | 0.00 mV |
| 反向 SOC 误差 max | **0.729 %SOC** | **0.000 %SOC** |
| 反向 SOC 误差 RMS | 0.139 %SOC | 0.000 %SOC |
| **台架实测工作点 4.177~4.208 V** | **0.008 %SOC** | 0.000 %SOC |

**误差不是均匀分布的，几乎全在两端**：

| SOC 区间 | 最大正向误差 |
|---|---|
| 0~5% | **−59.55 mV** |
| 5~10% | −5.33 mV |
| 10~95% | **±1.4 mV 以内** |
| 95~100% | **+14.46 mV** |

根因：
- **0~2% 段**：放完电的截止回弹极陡（0%→0.37% 电压就涨 128 mV）。
  当前表只用 `(0, 3.0818)` 与 `(2, 3.4516)` 两点连直线，把这个凸起削平了。
- **95~100% 段**：真值在 98.34% 有一个明显拐点（4.4278 V），
  当前表用 97%→99%→100% 的直线把它拉平。

> ⚠️ **重要边界**：上一轮用户感觉到的「SOC 与手算差 6.4%」**不是这张表的误差**。
> 那是把静置电压直接拿到 1C 带载曲线上反查造成的（差 82 mV IR）。
> 台架实际工作区（73~75% SOC）当前表只差 **0.008 %SOC**，换表几乎不改变读数。
> 换表的收益集中在 0~5% 与 95~100% 这两个**极化/截止不确定性本来就远大于 1 mV**
> 的区段。

## 二、方法

1. 取工步 5 全部 62 个 `(容量, 电压)` 原始点。
2. 真值折线：`SOC = (1 − cap/Q) × 100`，`OCV = V + 0.082`（1C×R0 = 12 A×6.8 mΩ = 81.6 mV，
   取整 82 mV；第 6 步静置第一秒 2.9998→3.0811 V 的 +81.3 mV 回弹是独立佐证）。
3. 正向扫描：SOC 0~100 每 0.05%，比 `ocv_from_soc(表)` 与真值折线。
4. 反向扫描：OCV 3.0818~4.4981 V 每 0.2 mV，比 `soc_from_ocv(表)` 与真值反查 —— 这才是底栏显示的误差。
5. 同时评估 `slope_at` / `kappa_at` 在 10~95% 工作区是否逐位不变（κ 决定电压回拉增益，
   EKF 的 `H[0] = slope_at/10` 也吃同一张表）。

## 七、「把 82 mV 缩小会不会更准」（2026-11-12 追加）

### 先澄清概念

**82 mV 不是「采集点间隔」**，它是带载曲线与 OCV 表之间的**垂直偏移量**：
`1C(12 A) × 单节内阻(6.8 mΩ) = 81.6 mV ≈ 82 mV`，用来把带载端电压还原成 OCV。
放电时端电压比 OCV 低这么多，查 OCV 表前要加回去。

真正的采样密度在原始 Excel 里是：

| 项目 | 实测 |
|---|---|
| 容量间隔 | 0.19994 Ah |
| SOC 间隔 | **1.639 %**（min 0.365，max 1.661） |
| 相邻点电压差 | 全量程 6.7~245.2 mV；**平台段(10~90%) 平均 14.7 mV** |
| 平台段斜率 | 约 8.98 mV/% |

### 实验 A：把 82 mV 缩小，重建 OCV 表

| α (mV) | 静置 SOC 偏差 | 1C 带载 SOC 偏差 | 表相对真值偏差 |
|---|---|---|---|
| **82（当前）** | ±0.00 % | −0.04 % | 0 mV |
| 75 | +0.73 % | +0.69 % | 7 mV |
| 70 | +1.25 % | +1.20 % | 12 mV |
| 60 | +2.25 % | +2.21 % | 22 mV |
| 40 | +4.17 % | +4.14 % | 42 mV |
| 0 | **+7.80 %** | +7.76 % | 82 mV |

⛔ **缩小只会引入系统性高估，不会提升精度**。因为运行时 IR 补偿仍是
`i_eff × r0_mohm = 81.6 mV`，表却整体下移了，反查必然落在更高的 SOC 上。
静置与带载的偏差几乎同向（分裂仅 0.04 %），所以这不是「带载补偿更细腻」，
而是把整条 SOC 曲线平移了。

### 实验 B：加密采样点（真值 = 原始 62 点折线）

| 方案 | 点数 | 反向 SOC 误差 max |
|---|---|---|
| **原始 62 点（不规则 SOC，当前表）** | **62** | **0.000000 %** |
| 等距 26 / 51 / 101 点 | 26~101 | 1.449 / 0.329 / 0.233 % |
| 等距 501 / 1001 点 | 501~1001 | 0.050 / 0.021 % |
| 保留原始拐点 + 加密到 184 / 370 / 680 点 | 184~680 | **0.000000 %** |

⛔ **加密没有收益**：折线段内本来就是线性插值，只要保留原始 62 个拐点，
加密到多少点误差都恒为 0。反而「等距整数 SOC 网格」要 1000 点以上才逼近，
因为 0.3654 % 和 98.3395 % 的拐点根本不在整数 SOC 上。

### 实验 C：真正的精度瓶颈是 AFE 噪声，不是表

用当前 62 点表把电压噪声折算成 SOC 抖动：

| 噪声 | @SOC25 (斜率 4.34) | @SOC50 (斜率 9.27) | @SOC75 (斜率 13.25) |
|---|---|---|---|
| ±0.5 mV | 0.115 % | 0.054 % | 0.038 % |
| ±1.0 mV | 0.231 % | 0.108 % | 0.075 % |
| ±2.2 mV（AFE 全温区最大） | **0.501 %** | 0.236 % | 0.167 % |
| ±4.4 mV（片间台阶） | 0.995 % | 0.468 % | 0.334 % |

- 125 节**均值**会把随机噪声压掉：`±2.2/√125 = ±0.197 mV` → SOC 仅 **±0.021 %**。
- 但**系统性**误差不会被平均：两片 AFE 之间的片间基准台阶 ≤4.4 mV；
  `X` 坏点数变化、超量程点回填数量变化会让 `clean_cells` 的均值逐轮跳变；
  82 mV 常数 IR 模型忽略极化、温度、老化。这些量级都是**几个 %SOC**，
  比表插值误差（现为 0）大两个数量级。

**结论**：⛔ 不要缩小 82 mV，⛔ 不用再加密表点。要提升精度只有三条路：
① 低倍率/逐点静置 OCV 标定（换掉常数 IR 模型）；② 温度与极化补偿；
③ 稳定清洗链路的均值（处理片间台阶与回填数量变化）——第 ③ 条正好就是
「空载时 SOC 微小波动」的根因，见 `soc_est.SocEstimator.update`。
