# SerialAssistant · SOC 估算 → ECU 移植交付包

**给谁**：电控组（把电池 SOC 估算从串口助手搬上 ECU 跑，BMS 算力不够）
**版本**：对应软件 v2.7（2026-11-11）

---

## 阅读顺序

1. **`SOC跑在ECU的操作步骤.pdf`** —— 先看这个。总操作步骤、易懂，含：
   - 系统架构（BMS → CAN → ECU → CAN → C125）
   - 输入数据契约（每轮喂什么、字段含义）
   - 6 步算法（带公式）
   - E74 参数一页纸（**62 点 OCV 表**，逐点贴合原始 1C 放电曲线）
   - ECU → C125 的 DBC / 帧布局
   - 联调验收判据
2. **`SOC估算技术说明.pdf` / `.html`** —— 算法深度说明（可选读）：OCV 曲线、清洗规则、κ 加权回拉、静置软锚定、电流判序、工况判别、验证矩阵。
3. **`算法源码/`** —— 真正要移植的代码（纯 Python，见下）。

## ⚠️ 移植注意：`soc_profiles.py` 的 Qt 依赖

`soc_profiles.py` 文件头有两行 PC 端依赖，**ECU 上应删掉**：

```python
from PySide6.QtCore import QSettings   # 删：PC 端读用户自定义电池包
import customization                   # 删：PC 端设置系统
```

删掉后，直接用 `soc_profiles.BUILTIN_PACKS` 里的参数即可，算法逻辑不受影响。
（保留这两行也能跑，但会连带引入整个 Qt + 设置系统，没必要。）

## 移植路径（概要）

1. 把 `算法源码/` 三个文件 + numpy 搬进 ECU 工程。
2. 按「操作步骤 PDF」的**输入数据契约**喂入每轮清洗后的 `cells` / `temps`（mV / ℃）。
3. 调 `SocEstimator(cfg, ...).step(v_cell_v, i_a, dt_s)` 得到 SOC（%）。
4. 新车型：往 `soc_profiles.BUILTIN_PACKS` 加一条（参考 E74 那条写 OCV 表 / Ah / R0）。
