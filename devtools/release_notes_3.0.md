# CQUFSAE 串口助手 v3.0

> Windows 10 / 11（64 位）

## 本次重点

### 设置面板：更紧凑、更顺手

- **三处两行合一**：时间戳显示（年月日 + 时钟显示年月日）、电压范围（下限～上限）、
  温度范围（下限～上限）各并成一排，面板少占三行
- **界面材质 → 材质效果** 顺序对调，「材质强度」改名「材质效果」，滑杆加长
- 分区之间加暗淡横线，分区标题缩小变淡，逻辑关联的挨在一起
- **无单位的数字框收窄**（100/140 → 74），带单位的（mV/℃/pt/Hz）按实测宽度撑开，
  单位不会被截断
- **合并行的两个设置项字体统一**：「电压数据行数 / 温度采集数据行数」「主题 /
  界面材质」「暂停定位行数 / 行数（最大化）」「SOC 数据来源 / 总电压来源」
  「启动时最大化 / 时保留任务栏」这五排，右边原来又粗又小，现在和左边完全一致
- 下拉框统一宽度；「本地 / 主控」两个短选项收得更窄；材质效果整行不缩
- 校验位的显示名改小写：`none / odd / even / mark / space`

### 连接方式切换：改成高斯模糊过渡

串口 ⇄ 蓝牙 切换不再是高度收展动画，改成**只糊串口开关那一行以下**、560ms 淡出。
修掉一个真实缺陷：蓝牙扫描收尾用的是撤不掉的定时器，切回串口 3.5 秒后会把
蓝牙 MAC 填进串口选择框。

### 监控面板：独立浮窗

监控面板之前被建成主窗里的子控件，导致「不可用」且关不掉。现在改成独立的
`Qt.Tool` 浮窗，能记住上次的位置和大小，拔掉副屏后会自动回到可见区域。

### 串口选择框两行显示

长设备名不再被截断；切到蓝牙时会清空串口选择（以前会残留上次的值）。

### 设置界面重排：逻辑关联的挨在一起

「定制功能」不再按写代码的顺序平铺，改成按用途分组，每组有小标题：

- **数据显示**：显示补零、接收区字体大小（带预览）、时间戳显示年 / 月 / 日、
  时钟显示年月日、暂停定位行数、高亮异常数据
- **数据判读**：电压下限 / 上限、断线阈值、温度下限 / 上限、历史数据采样间隔
- **SOC**：显示 SOC 读数、SOC 数据来源、总电压来源、SOC 四状态 EKF
- **启动与窗口**：启动时最大化、最大化时保留任务栏、默认折叠发送区、
  读串口时保持屏幕唤醒
- **动画**：动画帧率

「开屏动画」挪到「启动与窗口」后面（都是开机时发生的事）；日志 / 会话数据库 /
协议 / MCP 收拢成「数据与接口」一组。车辆信息仍保持在面板最上面，未动。

### 串口设置：每一项都能单独开关

设置 → 界面按钮 → **串口设置**，从原来的 3 个组开关拆成逐项：

- 波特率、停止位、数据位、校验位（各收一行，互不影响）
- 保留行数
- 六颗动作按钮：监控面板、查看标记、近期数据、历史数据、历史报错、DLC

关掉一组里的最后一项时，整组自动收起（不留光秃秃的标题）；蓝牙广播模式下
串口参数四行依旧整体隐藏、DLC 依旧只在蓝牙模式出现。老配置里隐藏过整组的，
升级后自动展开成对应的逐项开关，选择不会丢。

### 赛季改成下拉选择

选车行里的「赛季」从手输数字框换成下拉（2000–2100，默认当年），不会输错年份。

### SOC / 总电压来源：本地 / 主控

两个下拉的选项统一为 **「本地」/「主控」**（存储值不变，老配置原样生效）：
本地 = 本机估算（安时积分 + OCV 回拉），主控 = 报文里主控上报的值。

### 悬停提示精简

- 文案统一收短：最长的一条 82 字 → 33 字（如总电压来源、近期 / 历史数据按钮）
- 提示框 padding 收紧，框贴着文字、不再大片留白；保持 8px 圆角
- 删掉「只列出带文字的按钮和下拉框…」那段说明（已被逐项开关取代）

### 稳定性修复

- **窗口全屏切换时偶发崩溃**：窗口已销毁但延迟回调还在跑，会踩到已删除对象。
  现在入口先判对象是否存活，已销毁就直接收手。
- **设置面板关闭后控制台报错**：点过「检查更新 / 导出 / 导入 / 车辆库 / 打开历史 /
  历史目录 / 导出数据库」之后几秒内关掉设置面板，定时器会把结果写回已经销毁的
  按钮上。三处已修（复制按钮、清除令牌、在线清单自动刷新）。
- **自动更新误报「已是最新」**：jsDelivr 的边缘缓存会返回旧版本文件，现已根治。

### 其它

- 首次启动链路提速。
- **exe 现在带 Windows 版本属性**：右键 → 属性 → 详细信息，可以直接看到
  文件版本 / 产品版本 / 公司名（以前这块是空的，任务管理器也读不到版本）。
- 版本号：3.0。
