# CQUFSAE 串口助手 v3.0

> Windows 10 / 11（64 位）

## 本次重点

### 设置界面重排：逻辑关联的挨在一起

「定制功能」不再按写代码的顺序平铺，改成按用途分组，每组有小标题：

- **数据显示**：显示补零、接收区字体大小（带预览）、时间戳显示年 / 月 / 日、
  时钟显示年月日、暂停定位行数、高亮异常数据
- **数据判读**：电压下限 / 上限、断线阈值、温度下限 / 上限、历史数据采样间隔
- **SOC**：显示 SOC 读数、SOC 数据来源、总电压来源、SOC 四状态 EKF
- **启动与窗口**：启动时最大化、最大化时保留任务栏、默认折叠发送区、
  读串口时保持屏幕唤醒
- **动画**：动画帧率

「开屏动画」挪到「启动与窗口」后面（都是开机时发生的事）；日志 / 会话数据库 /
协议 / MCP 收拢成「数据与接口」一组。车辆信息仍保持在面板最上面，未动。

### 串口设置：每一项都能单独开关

设置 → 界面按钮 → **串口设置**，从原来的 3 个组开关拆成逐项：

- 波特率、停止位、数据位、校验位（各收一行，互不影响）
- 保留行数
- 六颗动作按钮：监控面板、查看标记、近期数据、历史数据、历史报错、DLC

关掉一组里的最后一项时，整组自动收起（不留光秃秃的标题）；蓝牙广播模式下
串口参数四行依旧整体隐藏、DLC 依旧只在蓝牙模式出现。老配置里隐藏过整组的，
升级后自动展开成对应的逐项开关，选择不会丢。

### 赛季改成下拉选择

选车行里的「赛季」从手输数字框换成下拉（2000–2100，默认当年），不会输错年份。

### SOC / 总电压来源：本地 / 主控

两个下拉的选项统一为 **「本地」/「主控」**（存储值不变，老配置原样生效）：
本地 = 本机估算（安时积分 + OCV 回拉），主控 = 报文里主控上报的值。

### 悬停提示精简

- 文案统一收短：最长的一条 82 字 → 33 字（如总电压来源、近期 / 历史数据按钮）
- 提示框 padding 收紧，框贴着文字、不再大片留白；保持 8px 圆角
- 删掉「只列出带文字的按钮和下拉框…」那段说明（已被逐项开关取代）
