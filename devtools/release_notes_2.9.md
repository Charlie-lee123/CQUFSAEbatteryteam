# CQUFSAE 串口助手 v2.9

> Windows 10 / 11（64 位）

## 本次重点

### 新增：最大化时可保留 Windows 任务栏

设置面板 → 定制功能 → **「最大化时保留任务栏」**（默认关 = 保持原来的整窗全屏）。

- 打开后，启动最大化、点标题栏最大化键、从任务栏还原、Windows 分屏（Win+↑/←/→）、
  以及**接收区展开**，都会使用标准最大化：铺满工作区、**露出任务栏**。
- 关掉则维持原样：铺满整块屏幕并盖住任务栏。
- 在设置里切换后**点确定立即生效**，不用重启。
- 已知限制：保留任务栏模式下，窗口客户区比 Windows 工作区每边大约多 7 逻辑像素
  （14 物理像素，dpr=2 时），会压住任务栏顶沿一条细线。这是自绘无边框窗口走原生
  最大化的固有行为；文字与图标完整可读，不影响使用。为保住 Win+↑ / 分屏等系统
  交互，未做几何强改。

### 修复：切换车号时「两套内容叠在一起」

切换车号时的模糊过渡层，此前会被系统**合成两遍** —— 屏幕上同时出现一套模糊、一套
清晰的模组行，左侧还残留一列被裁掉一半的字。根因是过渡层控件带了半透明属性，其内容
被重复合成，且第二遍的位移量恰好等于过渡层自身在面板里的坐标。

现在过渡层改为不透明控件（底图整块替换 + 模糊层按透明度淡入），叠影消失。

## 其他改进

### 历史数据打开更快

打开「历史数据」回看时，同一份数据**第二次及以后打开快约一倍**（实测 4.9 秒 → 2.5 秒，
35.8 万行）。做法是缓存排版结果，行数、时间戳、着色与内容逐字一致。
首次打开仍需完整排版一次（耗时主要在把几十万行装进文本框，这部分省不掉）。

### 安装包更小

裁掉 numpy 里未被使用的子包（fft / random / testing / ma / f2py）及其二进制扩展，
单文件与安装包各减小约 1.4 MB。开屏与车号毛玻璃使用的高斯模糊**完全保留**，观感不变。

### 代码清理

删除 `updater.py` 里一处被立即覆盖的死赋值，合并一处重复条件判断。行为零变化。

## 已知限制

- 「最大化时保留任务栏」下从最小化还原时，若期间改过分辨率或换过主屏，Windows 可能
  不把窗口恢复成最大化；此时手动再点一次最大化即可。
- 「最大化时保留任务栏」下按 Esc / 点还原退出时，不再播放全屏版式的快照缩放动画
  （直接落回普通窗口），这是为避免动画按全屏版式计算而在有任务栏时错位。
