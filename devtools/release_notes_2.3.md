# SerialAssistant v2.3

界面细节收口 + 再瘦一圈。本版本合并了原 **2.3 / 2.3.1 / 2.3.2** 三个版本
（后两者不再单独发布），下载到的就是 **2.3 系列的最终形态**。
功能与 v2.2 一致，没有新增/删改任何数据字段 —— **升级不需要迁移，车辆档案与历史数据原样保留**。

> 说明一：安装包与程序的内部版本号仍是 `2.3.2`（2.3 系列的最后一个构建），对外统一并入 v2.3。
>
> 说明二：2.3 最初发布于 **2026-10-22**，本页是合并 2.3.1 / 2.3.2 之后的重新发布，
> 所以侧栏日期显示为合并当天（2026-11-12）—— **不是** 新版本，功能与 v2.2 一致。

## 2.3：界面细节收口

- **控件尺寸按内容来**：设置面板里的「主题 / 界面材质 / 编码」等下拉框改成定宽
  （不再拉满整列），面板最小宽度 580 → 560。
- **车辆行收成一行**：「赛季 / 车号 / ＋ / 模组数」并排，去掉左侧「车辆」标签，
  「模组数」移到框外当标签；新建用的 ＋ 去掉描边（只留字形，悬停提亮）。
- **页头常显当前车**：「串口调试助手」下面一行小字「2026 赛季 · E74」，
  居中在标题中轴线上，改车实时跟随；没选车时不显示。
- **数字框竖直居中改算法**：不再靠抓图量墨迹（打包版里会失准），改按字体度量算，
  并在显示后补几拍纠正；数字框内层编辑框去掉自带底色，框底不再漏一条浅带。
- **数量框**：去掉量词「个」，补全站统一的圆角 / hover / 聚焦样式，数字居中。

## 2.3.1：两处中文标签换英文

- **串口校验位下拉改英文**：`None / Odd / Even / Mark / Space`（原来混着
  `none / 奇 / 偶 / 标记 / 空格`）。存储值与显示名已经拆开，以后换文案不会再影响配置；
  老配置里的中文键**自动归一**，升级后照常生效。
- **逐模组行标题改英文**：`模组 1` → `Module 1`（后面的「电芯数量 / 温度采集数量」保持原样）。
- 顺手修掉一个显示问题：没选车时车号框里的「（未选择）」被截成「（未选」，
  占位文字缩成「未选择」。

## 2.3.2：数字框居中与弹层方框

- **数字框数据居中**：「赛季」「车号」「模组数」三处的值改为水平居中，与下面的
  电芯 / 温度数量框同一观感。⛔ 根因顺带修掉：Qt 内部布局仍给隐藏的上下按钮保留
  22px，行内编辑框被压窄且靠左 —— 居中只在编辑框里生效，对整个框还是左偏 11px。
  无箭头模式下由 `_place_edit` 接管编辑框横向几何 + 对称 textMargins（实测偏差 ±0.2px）。
- **逐模组两组输入间距加大**：「电芯数量」与「温度采集数量」之间从 14px 加到约 50px，
  两组不会再糊在一起。
- **赛季 / 模组数去掉上下箭头**：这两个值只能手动输入 —— 箭头暗示"能点着调"，
  而调一下就是一套电池箱结构。（其它数字框如电压上下限、保留行数**保留箭头**，
  它们需要快速步进。）
- **修掉浅色主题下拉展开后的一圈「方框」**：Windows 11 会给弹层窗口画**方角**阴影，
  深色主题下与卡片同色看不出来，浅色下白底上就是一圈灰方框。现在让系统把弹层当
  圆角窗处理（Win11 的 DWM 圆角属性），阴影跟着圆角走。Win10 没有这个属性，
  自动忽略、保持原样。

## 瘦身

包体 **35.2MB → 34.4MB**（−824KB）。这一轮裁掉的是**从未加载**的 Qt 插件：

| 插件 | 大小 | 为什么能删 |
| --- | --- | --- |
| qdirect2d（平台插件） | 457KB | Qt 默认走 qwindows，direct2d 是可选平台 |
| qminimal / qoffscreen | 72KB | 只有显式设 `QT_QPA_PLATFORM` 才用，产品从不设 |
| qgif / qicns / qtga / qwbmp / qpdf | 113KB | 只用到 png（内置）/ ico / svg / jpeg |
| qtuiotouchplugin / qtvirtualkeyboardplugin | 65KB | 无触摸 / 虚拟键盘输入 |
| qmodernwindowsstyle | 109KB | 启动即 `setStyle("Fusion")`，原生样式不加载 |

代码侧：删掉未使用的 `season_list()`、清理未用循环变量；静态检查（ruff + vulture）零告警。
